المهارة المختارة: البحث التقني (Technical Research)

*ليه اخترت المهارة دي؟*

لأن مش كل مشكلة هتقابلني في البرمجة هلاقي حد يشرحلي حلها، فلازم أتعلم إزاي أبحث بطريقة صحيحة وأوصل للمعلومة من مصادر مختلفة.

*التجربة العملية:*

اخترت سؤال تقني:
Why is my Python code not printing any output?

وجربت أبحث عنه بثلاث طرق مختلفة:

1. البحث الأول:
   Python code not printing output.

2. البحث الثاني:
   Why is my print function not working in Python?

3. البحث الثالث:
   Python program runs but nothing appears in the output terminal.

مقارنة النتائج:

- البحث الأول: أظهر نتائج عامة عن مشاكل عدم ظهور المخرجات
-print البحث الثاني: ركز على المشكلات المتعلقة بدالة 
-Terminal البحث الثالث: أظهر نتائج أكثر تحديدًا عن مشكلات تشغيل البرنامج والـ

*النتيجة:*

اكتشفت إن طريقة صياغة السؤال بتفرق جدًا في جودة نتائج البحث، 
وإن كل ما كان البحث محدد وواضح، كانت فرصة الوصول للحل المناسب أكبر.

*استفدت إيه من التجربة؟*

اتعلمت إني قبل ما أطلب المساعدة، أحاول أفهم المشكلة وأحددها 
وأبحث عنها بأكثر من صيغة، وأقارن بين النتائج بدل ما أعتمد على أول إجابة تظهر لي.
